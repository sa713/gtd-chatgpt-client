Настрой мою личную среду Codex для управления существующим GTD через HTTP API.
Работай в корне выбранного клиентского репозитория, прочитай AGENTS.md и WORKFLOW.md.
Сервер: https://gtd.sergeantipov.ru, префикс API /api/agent/v1.

В клиенте используется только стандартная библиотека Python. Проверь Python 3.10+
и синтаксис gtd_agent.py. Устанавливать зависимости, запускать локальный сервер
или разворачивать GTD не нужно.

В настройках среды:
- название: gtd; кто может использовать: только я;
- интернет: разрешён, набор Custom domains only; дополнительный разрешённый
  домен: gtd.sergeantipov.ru;
- обычная переменная GTD_AGENT_ORIGIN=https://gtd.sergeantipov.ru;
- запросить переменную GTD_AGENT_TOKEN с областью Личное, без значения в настройках
  общей среды. Мой ключ будет введён в защищённое поле личного хранилища.

Никогда не проси вставить ключ в сообщение и не выводи его. Если значение ещё
не задано, объясни, в какое поле интерфейса его вставить. Не создавай .env
и не записывай ключ в репозиторий или другие файлы. Не отключай TLS.

Скрипт установки: python3 -c 'import sys; assert sys.version_info >= (3,10)'

Навык для запуска:
«Работай с моим GTD через HTTPS API https://gtd.sergeantipov.ru/api/agent/v1.
Прочитай AGENTS.md и WORKFLOW.md в клиентском репозитории. Используй
python3 gtd_agent.py. GTD_AGENT_TOKEN поступает из моего личного хранилища;
никогда не выводи и не сохраняй значение. Перед работой вызови GET /capabilities
и GET /workspaces. Читай реальные карточки и revision перед изменениями.
Для потока мыслей используй /inbox/capture; для разбора — черновики API.
При неоднозначном сбое сохраняй исходные тело и request_key. Обычные поручения
относятся к задачам, а не к изменению клиента или развёртывания сервера.»

После задания ключа проверь только чтение: GET /capabilities, GET /workspaces
и GET /reviews/daily. Если команде нужно сетевое разрешение, используй штатное
разрешение для этой команды, сохраняя ограниченный список доменов. Не создавай
тестовые карточки автоматически. После успешной проверки предложи сохранить
и опубликовать среду. Затем проверка чтения должна пройти в новом чате этой среды.
