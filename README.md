# GTD в своём ChatGPT

Это небольшой клиент личных карточек на https://gtd.sergeantipov.ru.
Каждый пользователь подключает свой аккаунт GTD к своему окружению Codex.
Приложение и база работают на сервере; здесь нет их исходников и пользовательских данных.

## Один раз подключить

1. Войди в GTD через Telegram. Открой **Настройки → Доступ для ChatGPT**.
   Создай свой ключ. Он показывается один раз; скопируй его для личного хранилища
   ChatGPT. Ключ не нужно отправлять сообщением.
2. Создай [собственную копию клиента кнопкой Fork в GitHub](https://github.com/sa713/gtd-chatgpt-client/fork).
   Если GitHub недоступен из GTD, скачай ZIP клиента в настройках, распакуй и
   загрузи файлы в свой отдельный репозиторий GitHub. Не загружай туда ключ.
3. В веб-версии ChatGPT открой **Настройки → Codex Cloud → Создать среду**.
   Подключи свой GitHub, если потребуется, и выбери репозиторий клиента.
   Вставь текст из SETUP.md в разговор настройки. Сохраняй доступ «Только я».
4. Когда среда запросит GTD_AGENT_TOKEN, вставь ключ именно в поле личной
   переменной. Его также можно заранее добавить через **Codex Cloud → Личное
   хранилище → Добавить → Переменная среды**: ключ переменной GTD_AGENT_TOKEN,
   значение — твой ключ GTD, применяется к выбранной среде gtd.
   Обычная несекретная GTD_AGENT_ORIGIN должна быть https://gtd.sergeantipov.ru.
5. Проверь успешное чтение, сохрани и опубликуй среду. Открой новый чат в этой
   среде и напиши «Покажи мои входящие». Новая настройка действует для новых чатов.

Окружение впервые создаётся через веб или компьютер. На телефоне можно продолжать
уже созданный чат; возможность выбора среды зависит от доступного интерфейса.
Обычный новый чат ChatGPT автоматически её настройки не получает.

## Пользоваться

- «Запиши во входящие: …» — можно диктовать потоком.
- «Покажи задачи на сегодня и до конца недели».
- «Разберём входящие».
- «Перенеси эту задачу на пятницу», «Добавь комментарий», «Готово».

Для каждого нового разговора выбирай свою опубликованную среду gtd. Вводить ключ
заново не нужно, пока он сохранён и действует. Ключ даёт доступ только к твоим
карточкам. Чужой ключ использовать нельзя. В настройках GTD можно отозвать
отдельное подключение, а затем при необходимости создать новое.

Ошибка 401 означает неверный или отозванный ключ; 403 — недостаточно прав;
429 — временный лимит. После сетевого сбоя нельзя считать запись выполненной.
Существующая сводка в Telegram не зависит от подключения ChatGPT.

Документация OpenAI: https://learn.chatgpt.com/docs/environments/cloud-environments
