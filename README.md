# GTD в своём ChatGPT

Здесь хранятся общие файлы для обращения к личным карточкам на
https://gtd.sergeantipov.ru. Приложение и база работают на сервере владельца.
Предполагается, что у пользователя уже есть работающая облачная среда Codex.

## Один раз подключить

1. Войди в GTD через Telegram. Открой **Настройки → Подключение ИИ**,
   создай личный ключ и сохрани его для защищённого поля ChatGPT.
   Значение показывается один раз; не отправляй его сообщением.
2. Нажми **ChatGPT → Скопировать инструкцию подключения**. В веб-версии ChatGPT открой
   **Настройки → Codex Cloud**, выбери существующую среду и нажми **Изменить**.
   Вставь инструкцию в разговор настройки. Codex сам создаст нужные файлы
   в отдельной папке; скачивать файлы и создавать копию репозитория не требуется.
   Самодостаточный текст инструкции также находится в [SETUP.md](SETUP.md).
3. Когда Codex запросит `GTD_AGENT_TOKEN`, вставь свой ключ в защищённое поле
   личной переменной. В личном хранилище значение применяется только к выбранной
   среде. Адрес сервера `GTD_AGENT_ORIGIN` — обычная несекретная переменная.
4. После успешного чтения сохрани и переопубликуй эту среду. Открой новый чат
   в ней и напиши «Покажи мои входящие».

Аккаунт GitHub пользователя и собственный сервер для этих шагов не нужны.
Настройка использует существующую среду; создание первого окружения сюда не входит.
Личный ключ не попадает в репозиторий или подготовленные файлы. Существующий
проект и остальные сценарии запуска среды сохраняются.

## Другой ИИ

API GTD не привязан к OpenAI. В общих настройках открой **Подключение ИИ → Другой ИИ**: инструкция
откроется сразу. В ней есть отдельная кнопка копирования.
Создай ключ с названием выбранного ИИ и передай ему эту инструкцию.
Она рассчитана на готового агента с Python 3.10+, файлами и доступом к HTTPS API;
например, подходящим образом настроенный Claude Code или Qwen Code.

Агент создаст файлы из инструкции и попросит подать `GTD_AGENT_TOKEN` через
защищённое хранилище его среды. Единой формы секретов для всех ИИ нет.
В инструкции есть вариант локального ввода без отображения для одного запуска;
он требует повторного ввода и не обещает постоянного хранения ключа.
Порядок действий и параметры прямого HTTP-доступа — в [OTHER_AI.md](OTHER_AI.md).
Обычного чата без нужных инструментов недостаточно. Сквозная проверка отдельного
Claude/Qwen пока не проводилась.

## Пользоваться

- «Запиши во входящие: …» — можно диктовать потоком.
- «Покажи задачи на сегодня и до конца недели».
- «Разберём входящие».
- «Перенеси эту задачу на пятницу», «Добавь комментарий», «Готово».

В Codex открывай разговоры в подключённой облачной среде. Вводить ключ заново не нужно,
пока он сохранён и действует. На телефоне можно продолжить готовый разговор.
Новый обычный чат автоматически настройки этой среды не получает.

Ключ даёт доступ только к твоим карточкам. В GTD можно отозвать отдельное
подключение. Ошибка 401 означает неверный или отозванный ключ; 403 — недостаточно
прав; 429 — временный лимит. Сетевой сбой не подтверждает сохранение карточки.
Существующая сводка в Telegram работает независимо от ChatGPT.

Документация среды: https://learn.chatgpt.com/docs/environments/cloud-environments
